# Customer Churn Prediction

A Machine Learning project that predicts whether a customer is likely to churn using the Telco Customer Churn dataset.

## Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Seaborn
- Scikit-learn
- Imbalanced-learn (SMOTE)
- XGBoost
- ipywidgets

## ML Model

Random Forest Classifier

## Features

- Data Cleaning
- Exploratory Data Analysis
- Label Encoding
- SMOTE
- Cross Validation
- Random Forest Classification
- Interactive Prediction UI
